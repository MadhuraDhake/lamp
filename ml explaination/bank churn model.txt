D. transform()
Code
X_test_processed = preprocessor.transform(X_test)

Notice that we are using transform(), not fit_transform().

Why?

Because the preprocessing rules have already been learned from training data.

We must use exactly the same rules for testing data.

For example:

Suppose training ages are:

20, 30, 40
The scaler learns the training mean and standard deviation.

Now testing age is:

35
We use the previously learned training mean and standard deviation to standardize 35.

We do not calculate a new mean from testing data.

Why is this important?

To avoid data leakage.

What is data leakage?
Data leakage happens when information from the testing dataset improperly influences the model's training process.

For example:

If we calculate the scaler's mean using both training and testing data, information from the test set enters the training preprocessing process.

This can make the evaluation misleading.

Correct approach:

Dataset

Operation

Training

fit_transform()

Testing

transform()

Remember this for your viva.

G. How does the ANN learn? Backpropagation
This is a very important theoretical concept.

The model initially does not know the correct weights.

It starts with initialized weights and makes predictions.

Suppose:

Actual answer = 1
Predicted probability = 0.30
The prediction is not very good.

The model calculates the error using its loss function.

Then backpropagation calculates how the weights contributed to the error by computing gradients.

An optimizer uses these gradients to update the weights.

This process repeats during training.

The cycle is:

1. Forward propagation

Generate prediction.

2. Calculate loss

Compare prediction with actual answer.

3. Backpropagation

Calculate gradients.

4. Optimizer

Update weights.

Repeat during training

Important distinction:

Forward propagation produces predictions.

Optimizer updates weights.
