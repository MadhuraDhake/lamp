\[
Precision = \frac{TP}{TP+FP}

recall_score



It measures how many actual positive cases were correctly identified.

Formula:
\[
Recall = \frac{TP}{TP+FN}
\]

5.5 What is median?
df[column] = df[column].fillna(df[column].median())



This line is especially important.

First, understand median.

Median is the middle value of a sorted dataset.

Example 1:
10, 20, 30, 40, 50


Median = 30.

Example 2:
10, 20, 30, 40


There are an even number of values.

Median is the average of the two middle values:
\[
Median = \frac{20+30}{2}=25
\]

Why do we use median?

Median is less affected by extreme values (outliers) than mean.

For example:
10, 20, 30, 40, 1000


Mean:
\[
\frac{10+20+30+40+1000}{5}=220
\]

Median:
\[
30
\]

The extreme value 1000 changes the mean significantly, but it does not change the median as much.

Therefore, median is often useful when a dataset contains outliers.
Now understand the code
df[column].median()



Calculates the median of the selected column.

6.2 What is a Box Plot?
A box plot is a graphical representation of numerical data.

It helps us understand:
- Median.
- First Quartile (Q1).
- Third Quartile (Q3).
- Interquartile Range (IQR).
- Potential outliers.
- Spread of the data.







paytonyau.github.io


Understand the five important parts
1. Minimum

The smallest value within the lower whisker.

2. Q1 – First Quartile

The value below which approximately 25% of observations lie.

3. Median – Q2

The middle value of the dataset.

50% of observations lie below it, and 50% lie above it.

4. Q3 – Third Quartile

The value below which approximately 75% of observations lie.

5. Maximum

The largest value within the upper whisker.
What is IQR?
IQR stands for Interquartile Range.

It measures the spread of the middle 50% of the data.

Formula:
\[
IQR = Q3-Q1
\]

Example:

Suppose:
Q1 = 20
Q3 = 60


Then:
\[
IQR = 60-20=40
\]

How are potential outliers identified?
The commonly used IQR method defines:
\[
Lower\ Bound=Q1-1.5(IQR)
\]

\[
Upper\ Bound=Q3+1.5(IQR)
\]

Values below the lower bound or above the upper bound are flagged as potential outliers.

Example:
Q1 = 20
Q3 = 60
IQR = 40


Lower bound:
\[
20-1.5(40)=-40
\]

Upper bound:
\[
60+1.5(40)=120
\]

Any value greater than 120 or less than -40 is flagged as a potential outlier.

Remember: Your code does not manually calculate or remove outliers. It only visualizes the features using box plots.

6.4 What is Correlation?
Correlation is a statistical measure that tells us how strongly two numerical variables are related.

For example:

Suppose we have two variables:
- Hours studied.
- Marks obtained.
If students who study more hours generally obtain higher marks, these variables may have positive correlation.
Three types of correlation









1. Positive correlation

When one variable increases, the other generally increases.

Example: Study hours and marks.












2. Negative correlation

When one variable increases, the other generally decreases.

Example: Speed and time taken to cover a fixed distance.












3. Zero or no linear correlation

There is no clear linear relationship between the variables.

Example: Shoe size and exam marks.



Correlation coefficient
Correlation is commonly represented by the letter r.

Its value ranges between -1 and +1.
Value	Meaning
+1	Perfect positive correlation
0	No linear correlation
-1	Perfect negative correlation

For example:
- 0.9 = Strong positive correlation.
- 0.5 = Moderate positive correlation.
- -0.8 = Strong negative correlation.
- 0.02 = Very weak linear correlation.
Correlation does not necessarily mean causation.

For example, two variables may increase together without one directly causing the other.

8.1 Why do we need Feature Scaling?
Suppose we have two people.
Feature	Person A	Person B

\[

\]

8.2 What is StandardScaler?
StandardScaler is a preprocessing technique from Scikit-learn.

It standardizes numerical data using the following formula:
\[
Z=\frac{X-\mu}{\sigma}
\]

Where:
- Z = Standardized value.
- X = Original value.
- μ = Mean of the feature.
- σ = Standard deviation of the feature.
Understand with a simple example
Suppose:
Mean = 50
Standard deviation = 10
Original value = 70


Using the formula:
\[
Z=\frac{70-50}{10}
\]

\[
Z=2
\]

So the standardized value is 2.

This means the original value is two standard deviations above the mean.

Another example:
Mean = 50
Standard deviation = 10
Original value = 30


\[
Z=\frac{30-50}{10}=-2
\]

The standardized value is -2.
What does a negative scaled value mean?
It means that the value is below the feature's mean.
What does a positive scaled value mean?
It means that the value is above the feature's mean.
Does StandardScaler make all values equal?
No.

It changes the scale of the values while preserving their relative differences and distribution shape.

The transformed training features have approximately:
- Mean = 0.
- Standard deviation = 1.

8.4 Second line – fit_transform()

This is one of the most important lines to understand.

It combines two operations:

What is fit()?
The fit() method calculates the mean and standard deviation of every feature using the training dataset.

For example:

It learns the scaling parameters from the training data.

It does not actually return the scaled dataset.
What is transform()?
The transform() method uses the learned mean and standard deviation to standardize the data.

For example:

It applies the scaling formula to the data.
What is fit_transform()?
It combines both operations.

Means:
1. Calculate the mean and standard deviation from X_train.
2. Use those values to standardize X_train.
3. Return the standardized data.
The result is stored in:

Why do we fit only on training data?
This is a very important ML concept called Data Leakage.

Data leakage happens when information from the testing dataset influences the training process.

We want to evaluate the model on genuinely unseen data.

Therefore:
- Learn scaling parameters from training data.
- Apply those same parameters to testing data.

9.2 How does KNN work?
The basic idea of KNN is:

Similar data points are likely to belong to the same class.

Suppose we have information about five people.

We want to predict whether a new person has diabetes.

KNN performs the following operations:
1. Takes the new person's feature values.
2. Calculates the distance between the new person and all training records.
3. Finds the K nearest records.
4. Checks the classes of those nearest records.
5. Selects the class with the majority votes.
Understand with an example
Suppose we select:
K = 5


The model finds the five nearest neighbors.

Their classes are:
Five nearest neighbors
1

Neighbor 1

0

Neighbor 2

1

Neighbor 3

1

Neighbor 4

0

Neighbor 5



Diabetes (1)
3 votes

No diabetes (0)
2 votes

Final prediction: Class 1

The majority of the nearest neighbors belong to class 1.


Therefore, the model predicts that the new person belongs to class 1.

This is called majority voting.
9.3 What is K in KNN?
K represents the number of nearest neighbors considered during prediction.

For example:
K value	Meaning
K = 1	Consider only the nearest neighbor
K = 3	Consider the three nearest neighbors
K = 5	Consider the five nearest neighbors
K = 7	Consider the seven nearest neighbors

In our practical:
n_neighbors=5



Therefore, K = 5.
Why did we choose 5?
K = 5 is a commonly used starting choice.

It is not necessarily the best K for every dataset.

The best value can be selected by experimenting with different K values and comparing model performance, ideally using cross-validation.
What happens if K is too small?
Suppose K = 1.

The model considers only one neighbor.

It may become sensitive to noise or unusual records.

This can lead to overfitting.
What happens if K is too large?
Suppose K = 100.

The model considers many neighbors.

The local patterns may become less important, and the model may underfit.

Therefore, choosing an appropriate K is important.
9.4 How does KNN calculate distance?
KNN commonly uses Euclidean distance.

Euclidean distance is the straight-line distance between two points.

Formula for two dimensions:
\[
d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}
\]

Let's understand with an example.

Suppose:

Person A:
Age = 20
BMI = 25


Person B:
Age = 23
BMI = 29


Distance:
\[
d=\sqrt{(23-20)^2+(29-25)^2}
\]

\[
d=\sqrt{3^2+4^2}
\]

\[
d=\sqrt{9+16}
\]

\[
d=\sqrt{25}=5
\]

So the distance between these two points is 5.

A smaller distance means the points are closer to each other.

What about our dataset?

Our dataset has eight features, not just two.

For eight dimensions, Euclidean distance is:
\[
d=\sqrt{\sum_{i=1}^{8}(x_i-y_i)^2}
\]

The algorithm calculates the distance using all eight standardized features.

The exact default distance metric used by KNeighborsClassifier is Minkowski distance with p=2, which is equivalent to Euclidean distance.

3. F1-score
F1-score is the harmonic mean of precision and recall.

Formula:
\[
F1=2\times\frac{Precision\times Recall}{Precision+Recall}
\]

Sometimes a model has good precision but poor recall, or good recall but poor precision.

\[

\]

5. Macro Average
Macro average calculates the average metric across all classes, giving equal importance to each class.

For example:
\[
Macro\ Precision=\frac{Precision_0+Precision_1}{2}
\]

It does not consider how many records belong to each class.
6. Weighted Average
Weighted average calculates the average metric across all classes while considering the number of records in each class.

Classes with more records receive greater weight.

This is useful when the dataset has unequal class distributions.

1. How KNN works and how majority voting predicts the result
What is KNN?
KNN stands for K-Nearest Neighbors.

It is a supervised machine learning algorithm used for:
- Classification – Predicting categories.
- Regression – Predicting numerical values.
In our practical, we use KNN for classification.

Our goal is to predict whether a person has diabetes or not.
- 0 = No diabetes.
- 1 = Diabetes.
How does KNN actually work?
Imagine that we have a dataset containing information about 100 people.

Each person has different medical measurements:
- Glucose
- Blood pressure
- BMI
- Age
- Insulin
- Other features
We already know whether these 100 people have diabetes or not.

Now, a new person comes. We want to predict whether this person has diabetes.

KNN follows these steps:
1. Take a new person's data
   
   Example: Glucose = 140, BMI = 32, Age = 45.
2. Calculate distances
   
   Calculate the distance between this new person and all the people in the training dataset.
3. Find K nearest neighbors
   
   If K = 5, select the five people having the smallest distances.
4. Perform majority voting
   
   Check how many of the five people belong to class 0 and class 1.
5. Predict the final result
   
   The class receiving the most votes becomes the predicted class.

What is K?
K represents the number of nearest neighbors considered by the algorithm.

For example:
K value	Meaning
K = 1	Consider 1 nearest person
K = 3	Consider 3 nearest people
K = 5	Consider 5 nearest people
K = 7	Consider 7 nearest people

In our practical:
knn_model = KNeighborsClassifier(n_neighbors=5)



Here:

n_neighbors=5 means K = 5.

The model considers five nearest neighbors when predicting the outcome.
What is distance in KNN?
KNN uses distance to identify similar data points.

The default distance metric in our practical is Euclidean distance.

Euclidean distance means the straight-line distance between two points.

Formula:
\[
d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}
\]

Let's understand with a simple example.

Suppose we have two people:
Feature	Person A	Person B
Age	20	23
BMI	25	29

Distance:
\[
d=\sqrt{(23-20)^2+(29-25)^2}
\]

\[
d=\sqrt{3^2+4^2}
\]

\[
d=\sqrt{9+16}
\]

\[
d=\sqrt{25}=5
\]

So, the distance between Person A and Person B is 5.

Remember: Smaller distance means more similarity in terms of the features being compared.

Our actual practical uses eight features, so the distance is calculated using all eight dimensions.
What is Majority Voting?
Majority voting means selecting the class that occurs most frequently among the nearest neighbors.

Let's take K = 5.

2. Why StandardScaler is necessary for KNN
This is extremely important because KNN is a distance-based algorithm.
First, understand the problem
Suppose we have two features:
- Age
- Insulin
Consider two people:
Feature	Person A	Person B
Age	25	30
Insulin	100	200

Differences:

Age:
\[
30-25=5
\]

Insulin:
\[
200-100=100
\]

Notice something?

The difference in Insulin is 100, whereas the difference in Age is only 5.

KNN calculates distance using these numerical differences.

Therefore, a feature with a much larger numerical scale can dominate the distance calculation.

This can cause problems because Age may also be an important feature, but its numerical contribution is much smaller.

This is why we use Feature Scaling.
What is Feature Scaling?
Feature scaling is the process of bringing numerical features onto a comparable scale.

It prevents features with larger numerical ranges from dominating distance calculations simply because of their units or magnitude.
What is StandardScaler?
StandardScaler is a feature-scaling technique provided by Scikit-learn.

It standardizes data using this formula:
\[
Z=\frac{X-\mu}{\sigma}
\]

Where:
Symbol	Meaning
Z	Standardized value
X	Original value
μ	Mean
σ	Standard deviation

Understand with a simple example
Suppose we have:
Original value = 70
Mean = 50
Standard deviation = 10


Apply the formula:
\[
Z=\frac{70-50}{10}
\]

\[
Z=\frac{20}{10}=2
\]

The scaled value is 2.

This means the original value is two standard deviations above the mean.

Another example:
Original value = 30
Mean = 50
Standard deviation = 10


\[
Z=\frac{30-50}{10}
\]

\[
Z=-2
\]

The scaled value is -2.

It means the original value is two standard deviations below the mean.
What happens after StandardScaler?
The transformed training data has approximately:
- Mean = 0.
- Standard deviation = 1.
It does NOT mean that all values become zero.

It means the values are transformed to a common scale.
Understand your actual practical code
First line
scaler = StandardScaler()



We create an object of the StandardScaler class.
Second line
X_train_scaled = scaler.fit_transform(X_train)



This performs two operations.

fit():

Calculates the mean and standard deviation of every feature using training data.

transform():

Applies the StandardScaler formula to the training data.

The standardized result is stored in X_train_scaled.
Third line
X_test_scaled = scaler.transform(X_test)



This applies the same scaling parameters to testing data.

Why don't we use fit_transform() again?

Because we must use the mean and standard deviation learned from training data.

If we calculate new scaling parameters using testing data, information from the test dataset would influence preprocessing.

This is called data leakage.
Difference between fit(), transform() and fit_transform()
Function	Meaning
fit()	Learns mean and standard deviation
transform()	Applies scaling
fit_transform()	Learns parameters and applies scaling

Why is StandardScaler especially important for KNN?
Because KNN calculates distances between data points.

Without scaling:
- Large numerical ranges may dominate distances.
- Smaller-range features may have less influence.
With scaling:
- Features are placed on a comparable scale.
- Distance calculations become more balanced.
Viva answer:

We use StandardScaler in KNN because KNN is a distance-based algorithm. Features having larger numerical ranges can dominate distance calculations. StandardScaler transforms the features to have approximately zero mean and unit standard deviation, making the distance calculation more balanced.

3. How to interpret TN, FP, FN and TP in a Confusion Matrix
This is one of the most important concepts in classification.
What is a Confusion Matrix?
A confusion matrix is a table used to evaluate the performance of a classification model.

It compares:
- Actual values – The correct answers in the dataset.
- Predicted values – The answers predicted by our model.
Our diabetes practical has two classes:
- 0 = No diabetes.
- 1 = Diabetes.
The confusion matrix has four important terms:
1. True Positive (TP)
2. True Negative (TN)
3. False Positive (FP)
4. False Negative (FN)
Understand each term with a real-life example
Imagine that our model predicts whether a person has diabetes.
1. True Positive (TP)
Actual = 1

Predicted = 1

The person actually has diabetes, and the model correctly predicts diabetes.
Correct prediction
Example:
Actual: Diabetes
Predicted: Diabetes


This is True Positive.
2. True Negative (TN)
Actual = 0

Predicted = 0

The person does not have diabetes, and the model correctly predicts no diabetes.
Correct prediction
Example:
Actual: No diabetes
Predicted: No diabetes


This is True Negative.
3. False Positive (FP)
Actual = 0

Predicted = 1

The person does not have diabetes, but the model incorrectly predicts diabetes.
Incorrect prediction
Example:
Actual: No diabetes
Predicted: Diabetes


This is False Positive.

It is also called a Type I Error.
4. False Negative (FN)
Actual = 1

Predicted = 0

The person actually has diabetes, but the model incorrectly predicts no diabetes.
Incorrect prediction
Example:
Actual: Diabetes
Predicted: No diabetes


This is False Negative.

It is also called a Type II Error.
