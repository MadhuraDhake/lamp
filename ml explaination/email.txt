PART 1 – Understanding the practical
1. What is the aim of this practical?
Aim: To implement Email Spam Detection using Machine Learning algorithms K-Nearest Neighbors (KNN) and Support Vector Machine (SVM), and compare their performance using evaluation metrics.

2. What is Email Spam Detection?
Email Spam Detection is a Machine Learning application that identifies whether an email is:

Spam: Unwanted or suspicious emails, such as fake lottery messages, advertisements, phishing attempts, etc.

Not Spam (Ham): Genuine emails, such as college notifications, work emails, personal messages, etc.

For example:

Email message

Classification

Congratulations! You won ₹10 lakh. Click here!

Spam

Your college exam timetable is released.

Not Spam

Claim your free iPhone now!

Spam

Meeting scheduled for tomorrow at 10 AM.

Not Spam

The objective is to train a computer to identify these patterns automatically.

3. What is Machine Learning?
Machine Learning (ML) is a branch of Artificial Intelligence in which computers learn patterns from data and use those patterns to make predictions or decisions without being explicitly programmed for every situation.

Simple example:

Suppose we give a computer 1,000 emails.

500 emails are labelled Spam.

500 emails are labelled Not Spam.

The computer studies the patterns in these emails.

For example, spam emails might frequently contain words such as:

Free

Win

Prize

Offer

Congratulations

After learning these patterns, we give the computer a new email.

It predicts whether that email is Spam or Not Spam.

This is called Machine Learning.

4. What type of Machine Learning is used?
This practical uses Supervised Machine Learning.

Supervised Learning means the model learns from already labelled data.

For example:

Email features

Prediction

Free, Prize, Win

1 (Spam)

College, Assignment, Notes

0 (Not Spam)

Lottery, Offer, Money

1 (Spam)

Here:

Input data (X): Email-related features.

Output data (y): Whether the email is Spam or Not Spam.

The model learns the relationship between X and y.

What is Classification?

Classification is a type of supervised learning in which the model predicts a category or class.

In our practical, there are two classes:

0 = Not Spam

1 = Spam

Therefore, this is a Binary Classification Problem because there are exactly two possible output classes.

5. Algorithms used in this practical
We are implementing two algorithms.

1. K-Nearest Neighbors (KNN)

Using K Nearest Neighbours algorithm in scenario tuning - SAS Users

KNN classifies a new data point based on the classes of its nearest neighbouring data points.

2. Support Vector Machine (SVM)

Support Vector Machine (SVM) in Python

SVM finds an optimal decision boundary (hyperplane) that separates different classes.

A. What is KNN?
KNN stands for K-Nearest Neighbors.

It is a supervised Machine Learning algorithm used for classification and regression.

It works on the concept of similarity or distance.

How does it work?

Suppose we have the following training data:

Student

Study hours

Result

A

1

Fail

B

2

Fail

C

8

Pass

D

9

Pass

Now a new student studies for 7 hours.

We want to predict whether the student will Pass or Fail.

KNN checks the nearest existing data points.

If we choose K = 3, it checks the three nearest neighbours.

Suppose:

Neighbour 1 = Pass

Neighbour 2 = Pass

Neighbour 3 = Fail

Majority vote = Pass.

Therefore, KNN predicts Pass.

What does K mean?

K represents the number of nearest neighbours considered while making a prediction.

In our practical:

KNeighborsClassifier(n_neighbors=5)

Here, K = 5.

This means the algorithm considers the five nearest data points to classify a new email.

Important: A small K can be sensitive to noise, whereas a very large K may make the model less sensitive to local patterns.

B. What is SVM?
SVM stands for Support Vector Machine.

It is a supervised Machine Learning algorithm used for classification and regression.

It tries to find the best possible boundary that separates different classes.

Example:

Imagine we have two groups of points:

Red points = Spam emails.

Blue points = Not Spam emails.

SVM draws a boundary between the two groups.

This boundary is called a Hyperplane.

The objective is to find a hyperplane that separates the classes with the maximum possible margin.

Important terms:

Hyperplane: The decision boundary separating different classes.

Support Vectors: The data points closest to the hyperplane.

Margin: The distance between the hyperplane and the nearest data points of both classes.

Kernel: A function that helps SVM handle data that cannot be separated easily using a straight boundary.

In our practical:

SVC(kernel='linear', random_state=42)

SVC means Support Vector Classifier.

kernel='linear' means we are using a linear decision boundary.

random_state=42 sets a reproducible random seed for operations that use randomness.

1. What is KNN?
KNN stands for K-Nearest Neighbors.

It is a Supervised Machine Learning algorithm used for:
1. Classification.
2. Regression.
It predicts the class or value of a new data point by examining the nearest existing data points.

Let's understand the name:
Word	Meaning
K	Number of neighbours to consider
Nearest	Closest according to a distance measure
Neighbors	Existing data points around the new point

In simple words:

KNN looks at the K closest data points and decides the output based on their values.
2. Why do we use KNN?
Suppose we have a dataset containing information about emails.

Some emails are Spam and some are Not Spam.

We want to classify a new email, but we don't know its category.

KNN helps us determine its category by comparing it with previously labelled emails.

For example:
- If a new email is similar to Spam emails, it is likely Spam.
- If it is similar to genuine emails, it is likely Not Spam.
KNN assumes that similar data points are generally located close to each other in the feature space.
3. How does KNN work?
Let's understand using a simple example.

Suppose we have the following training data:
Email	Number of suspicious words	Actual Class
A	2	Not Spam
B	3	Not Spam
C	8	Spam
D	9	Spam
E	7	Spam

Now we receive a new email with 6 suspicious words.

We don't know whether it is Spam or Not Spam.

Let's use K = 3.

Step 1: Calculate the distance

Our new email has a value of 6.

We calculate the distance between it and each existing email.

For this one-dimensional example:
\[
Distance=|New\ Value-Existing\ Value|
\]

Email	Existing value	Distance from 6	Class
A	2	4	Not Spam
B	3	3	Not Spam
C	8	2	Spam
D	9	3	Spam
E	7	1	Spam

Step 2: Find the nearest neighbours

We select the three smallest distances.
Neighbour	Distance	Class
E	1	Spam
C	2	Spam
B	3	Not Spam

Step 3: Perform majority voting

Now count the classes:
- Spam = 2 votes.
- Not Spam = 1 vote.
Spam has the majority.

Step 4: Final prediction
Predicted: Spam
KNN classifies the new email as Spam.

That's how KNN works!
4. What is the value of K?
K represents the number of nearest neighbours that the algorithm considers before making a prediction.

For example:
- K = 1 → Consider only the closest neighbour.
- K = 3 → Consider the three closest neighbours.
- K = 5 → Consider the five closest neighbours.
- K = 7 → Consider the seven closest neighbours.
How does changing K affect predictions?
Suppose the nearest seven neighbours are:
Neighbour	Class
1	Spam
2	Spam
3	Not Spam
4	Spam
5	Not Spam
6	Not Spam
7	Not Spam

If K = 3:
- Spam = 2.
- Not Spam = 1.
Prediction = Spam.

If K = 7:
- Spam = 3.
- Not Spam = 4.
Prediction = Not Spam.

Therefore, changing K can change the prediction.
What happens if K is too small?
Suppose K = 1.

The model considers only one neighbour.

It can be affected by noise or an incorrectly labelled data point.

This can cause overfitting.
What happens if K is too large?
Suppose K = 100.

The model considers 100 neighbours.

It may consider many points that are not really similar to the new data point.

This can cause underfitting.
What is overfitting?
Overfitting happens when a model learns the training data too closely, including noise and unnecessary patterns.

It performs well on training data but poorly on unseen data.
What is underfitting?
Underfitting happens when a model is too simple to learn the important patterns in the dataset.

It performs poorly even on training data.
5. Why do we often choose an odd value of K?
In binary classification, we often choose an odd value such as:
- 3
- 5
- 7
- 9
This reduces the possibility of a tie during majority voting.

For example, if K = 4:
- Spam = 2 votes.
- Not Spam = 2 votes.
There is a tie.

If K = 5, a tie between two classes is impossible in ordinary unweighted binary majority voting.

However, an odd K does not guarantee that ties are impossible for three or more classes.
6. What is distance in KNN?
Distance tells us how close or far two data points are.

KNN uses distance to find neighbouring points.

There are different distance measures.
A. Euclidean Distance







medium.com


It is the straight-line distance between two points.

Formula:
\[
d=\sqrt{\sum_{i=1}^{n}(x_i-y_i)^2}
\]

For two-dimensional points:
\[
d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}
\]

Example:

Point A = (2, 3)

Point B = (5, 7)
\[
d=\sqrt{(5-2)^2+(7-3)^2}
\]

\[
d=\sqrt{9+16}
\]

\[
d=\sqrt{25}=5
\]

Therefore, the distance is 5.
B. Manhattan Distance
It calculates distance by adding the absolute differences between coordinates.

Formula:
\[
d=|x_1-y_1|+|x_2-y_2|
\]

Example:

A = (2, 3)

B = (5, 7)
\[
d=|5-2|+|7-3|
\]

\[
d=3+4=7
\]

C. Minkowski Distance
It is a generalized distance measure.

Formula:
\[
d=\left(\sum_{i=1}^{n}|x_i-y_i|^p\right)^{1/p}
\]

- When p = 1, it becomes Manhattan Distance.
- When p = 2, it becomes Euclidean Distance.
In Scikit-learn, KNN commonly uses Minkowski distance with p = 2 by default, which corresponds to Euclidean distance.
7. Why do we use StandardScaler with KNN?
This is very important for your practical.

Suppose we have two features:
Email	Word count	Number of links
A	500	2
B	600	4

The word count values are in hundreds, while link counts are in single digits.

KNN calculates distances using these features.

If we don't scale them, word count can dominate the distance calculation.

StandardScaler converts features into comparable scales.

Formula:
\[
z=\frac{x-\mu}{\sigma}
\]

Where:
- x = Original value.
- μ = Mean.
- σ = Standard deviation.
- z = Standardized value.
That's why your practical uses:
StandardScaler()



before KNN.
8. Is KNN a lazy learning algorithm?
Yes!

KNN is called a Lazy Learning Algorithm.

Why?

Because it does not build a traditional model or decision boundary during training.

Instead, it stores the training data and performs the distance calculations when a new prediction is requested.

For example:
knn.fit(X_train, y_train)



The algorithm stores the training examples.
knn.predict(X_test)



It calculates distances and predicts the classes.
9. KNN in your practical
Your actual code:
knn = make_pipeline(    StandardScaler(),    KNeighborsClassifier(n_neighbors=5))knn.fit(X_train, y_train)knn_pred = knn.predict(X_test)



Meaning:
1. make_pipeline() combines preprocessing and classification.
2. StandardScaler() standardizes the features.
3. KNeighborsClassifier() creates the KNN classifier.
4. n_neighbors=5 means K = 5.
5. fit() trains the model by storing the training examples.
6. predict() predicts the classes of testing emails.
10. Advantages and disadvantages of KNN
Advantages:
1. Easy to understand and implement.
2. No complicated training process.
3. Can be used for classification and regression.
4. Can work well when similar data points belong to similar classes.
5. Can handle nonlinear decision boundaries.
Disadvantages:
1. Prediction can be slow for large datasets.
2. Requires storing training data.
3. Sensitive to feature scaling.
4. Sensitive to irrelevant features and noisy data.
5. Choosing the correct K is important.
6. Performance can decrease with many dimensions (curse of dimensionality).

PART 2 – SVM (Support Vector Machine)

1. What is SVM?
SVM stands for Support Vector Machine.

It is a Supervised Machine Learning algorithm used for:
1. Classification.
2. Regression.
Its main objective is to find the best possible decision boundary that separates different classes of data.

In simple words:

SVM tries to draw the best boundary between two groups so that the groups are separated as clearly as possible.

For our practical:
- One group represents Spam emails.
- Another group represents Not Spam emails.
SVM learns a boundary to distinguish between them.
2. Why do we use SVM?
Suppose we have a dataset containing:
- Spam emails.
- Not Spam emails.
Each email has numerical features, such as word frequencies and other characteristics.

We want to classify new emails.

SVM finds a boundary between the two classes based on their feature values.

When a new email arrives, SVM checks which side of the boundary it falls on.
- One side = Spam.
- Other side = Not Spam.
This is how SVM makes predictions.
3. Understanding Hyperplane
A Hyperplane is a decision boundary that separates different classes.

Let's understand with a simple example.

Suppose we have two features:
- X-axis = Number of suspicious words.
- Y-axis = Number of suspicious links.
We have two groups:
- Red points = Spam.
- Blue points = Not Spam.
SVM tries to draw a line that separates these two groups.







hassothea.github.io


In a two-dimensional dataset, the hyperplane is a line.

In a three-dimensional dataset, it is a plane.

In higher dimensions, it is called a hyperplane.

Important:

A hyperplane is not always a straight line in the original input space when we use nonlinear kernels. It represents the decision boundary in the relevant feature space.
4. What are Support Vectors?







medium.com


Support Vectors are the data points closest to the decision boundary.

They are extremely important because they help determine the position and orientation of the optimal hyperplane.

Let's understand with an example.

Suppose we have two groups of points:
- Spam group.
- Not Spam group.
SVM draws a boundary between them.

Some points are very close to this boundary.

These closest points are called Support Vectors.

Why are they important?

Because the position of the optimal decision boundary is determined by the support vectors.

If the support vectors change, the decision boundary may also change.

Remember:

Support Vectors = Closest data points to the decision boundary.
5. What is Margin in SVM?







diamondclover.com


Margin is the distance between the decision boundary and the nearest data points from each class.

SVM tries to find a hyperplane with the maximum margin.

Why?

A larger margin generally helps the model generalize better to unseen data.

Imagine two possible boundaries:
- Boundary A has a very small margin.
- Boundary B has a larger margin.
SVM prefers Boundary B, provided the data and optimization conditions allow it.

This is called Maximum Margin Classification.
Important terms
Term	Meaning
Hyperplane	Decision boundary
Support Vectors	Closest data points to the boundary
Margin	Distance between the boundary and nearest data points
Maximum Margin	Finding the boundary with the largest possible margin

6. How does SVM work? Step by step
Suppose we have a dataset containing Spam and Not Spam emails.

Step 1: Take the training data

SVM receives the training features and their corresponding class labels.

Step 2: Identify possible separating boundaries

It considers possible decision boundaries that can separate the two classes.

Step 3: Identify support vectors

It identifies the data points that determine the margin.

Step 4: Calculate the maximum margin

It finds the decision boundary that maximizes the margin between the classes.

Step 5: Train the model

It learns the decision function.

Step 6: Predict new data

When a new email arrives, the model checks which side of the learned decision boundary it belongs to.

It predicts Spam or Not Spam.
7. What is Kernel in SVM?
This is one of the most important concepts in SVM.

A Kernel is a function used by SVM to handle data in different feature spaces, particularly when a linear decision boundary is insufficient.

Let's understand why we need it.
Example: Linearly separable data
Suppose two classes can be separated using a straight line.







linguisticmaz.medium.com


Here, a Linear Kernel can work well.
Example: Non-linearly separable data
Suppose the data is arranged in a circular pattern.

One class is inside the circle and another class surrounds it.







wasilzafar.com


A straight line cannot properly separate these classes.

Here, we can use a nonlinear kernel such as RBF.

Kernels help SVM construct more flexible decision boundaries.
Types of Kernels
There are four commonly discussed kernels:









1. Linear Kernel

Used when data can be separated using a linear decision boundary.

In your practical:
SVC(kernel='linear')















2. Polynomial Kernel

Used to model polynomial relationships between features.

Example:
SVC(kernel='poly')















3. RBF Kernel

RBF stands for Radial Basis Function.

It can handle complex nonlinear decision boundaries.
SVC(kernel='rbf')















4. Sigmoid Kernel

Uses a sigmoid-based mathematical function.
SVC(kernel='sigmoid')






Which kernel are we using in our practical?
kernel='linear'



We are using the Linear Kernel.

This means our SVM uses a linear decision boundary in the input feature space.
8. What is C in SVM?
Another important parameter is C.

C is called the Regularization Parameter.

It controls the trade-off between:
- Maximizing the margin.
- Minimizing classification errors on the training data.
If C is large:
- The model penalizes classification errors more strongly.
- It tries harder to classify training points correctly.
- It may create a narrower margin.
- It can become more sensitive to noise.
If C is small:
- The model allows more training errors.
- It gives more importance to maintaining a wider margin.
- It applies stronger regularization.
In Scikit-learn, the default value is:
C=1.0



Your practical does not explicitly specify C, so it uses the default.
9. What is Linear SVM?
Linear SVM is an SVM model that uses a linear decision boundary.

For example, in two dimensions, it separates the classes using a straight line.

A simplified mathematical equation is:
\[
w^Tx+b=0
\]

Where:
- \(w\) = Weight vector.
- \(x\) = Input feature vector.
- \(b\) = Bias.
- \(0\) = Decision boundary condition.
The model uses the learned weights and bias to decide which class a new data point belongs to.
10. Is SVM a lazy or eager learning algorithm?
SVM is an Eager Learning Algorithm.

Why?

Because it learns a decision function during training.

For example:
svm.fit(X_train, y_train)



During training, SVM learns the decision boundary.

Then:
svm.predict(X_test)



It uses the learned decision function to classify testing data.

This is different from KNN, which stores training data and calculates neighbours during prediction.
11. SVM in your practical
Your actual code:
svm = make_pipeline(    StandardScaler(),    SVC(kernel='linear', random_state=42))svm.fit(X_train, y_train)svm_pred = svm.predict(X_test)



Let's understand:
Code	Purpose
make_pipeline()	Combines preprocessing and classification
StandardScaler()	Standardizes features
SVC()	Creates SVM classifier
kernel='linear'	Uses linear kernel
random_state=42	Sets a random seed
fit()	Trains the SVM model
predict()	Predicts testing data classes

12. Advantages and disadvantages of SVM
Advantages:
1. Effective in high-dimensional feature spaces.
2. Can handle linear and nonlinear classification.
3. Uses support vectors to determine the decision boundary.
4. Can work well when there is a clear margin of separation.
5. Supports different kernel functions.
Disadvantages:
1. Training can be computationally expensive for large datasets.
2. Selecting the correct kernel and parameters can be difficult.
3. Requires feature scaling in many practical applications.
4. Can be sensitive to overlapping classes and noise.
5. It is less straightforward to interpret than some simpler models.

PART 4 – KNN vs SVM using one simple example
Imagine you are a teacher and want to classify students into two categories:
- Pass
- Fail
You have existing student records.

Now a new student arrives.

How would KNN classify the student?

It checks the nearest students based on their marks or other features.

If most of the nearest students belong to Pass, it predicts Pass.

How would SVM classify the student?

It learns a decision boundary separating Pass and Fail students.

It checks which side of that boundary the new student falls on.

That's the fundamental difference.
